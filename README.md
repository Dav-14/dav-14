### How I work

**AI as a collaborator. Engineering judgment stays human.**

I work with Claude Code and Codex to explore ideas, implement changes, and challenge assumptions.
I care about clear contracts, focused tests, and checking results against the source.

- **Make it reproducible.** Nix for development environments, Just for repeatable workflows.
- **Make it understandable.** Explicit ownership, clear documentation, and actionable failures.
- **Keep learning.** Connect notes, decisions, and evidence into a personal knowledge system.
